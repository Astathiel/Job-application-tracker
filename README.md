# Job Application Tracker

A modern(somewhat), minimalistic Windows Forms desktop application built in C# for tracking ongoing job applications and their states.

## Tech Stack
- C# & .NET
- Windows Forms (UI)
- System.Text.Json (Local Data Persistence)
